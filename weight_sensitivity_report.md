### 3. Topics with No Meaningful Profile Sensitivity (Configuration Dead-Zones)
These topics showed absolutely no change in final evaluation regardless of profile. **WHY no change occurred:** This usually occurs when the Mock Search Provider only returned one type of result (e.g. only Tier A, or only Tier C), meaning the dynamic weights had no alternative sources to prioritize. If only Law documents are found, even the 'practical_blog' profile must select Law as the top source.
- 상수도 적용 기준
- 구조해석 시공 전 필수 설계 검토사항
- 교대 기본 설계 원리 및 검토사항
- 터널발파 적용 기준
- 라이닝 적용 기준

## Recommendations for Improving Profile Differentiation
1. **Enhance Search Diversity:** Ensure the Mock Search Provider returns a wider variety of sources (Tier A/B/C/D) for every query. Dead-zones are caused by a lack of diverse evidence to re-rank.
2. **Adjust Readiness Thresholds:** Research readiness could be tied directly to the *presence* of the top-weighted tier for the active profile, rather than a cumulative score. For example, 'regulation_focus' might require Tier A to be 'high' readiness, whereas 'practical_blog' could achieve 'high' readiness with only Tier C.
3. **Widen Weight Deltas:** The differences between weights in `weights.json` could be increased to force more dramatic re-ranking, especially for borderline sources.
