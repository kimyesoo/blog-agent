1. 생성/수정한 파일
- 새로 생성: topic_research_agent.py, topic_research/topic_candidates.json
- 수정: README.md

2. Topic Research Agent의 동작 방식
- 지정한 분야(기본: 토질시험)의 시드 데이터(기본물성시험, 입도시험 등)와 의도 템플릿(정보탐색, 시험방법, 결과해석 등)을 조합하여 후보를 생성합니다.
- 생성된 후보들을 기존 posts.json의 글 제목과 비교(공백 제거 등 정규화 활용)하여 중복을 필터링합니다.
- API 통신 없이 로컬 로직으로 작동하며, JSON 객체 형태로 상세 메타데이터(intent, cluster, 실무 가치 등)를 포함하여 저장합니다.

3. 생성된 후보 개수
- 158개 생성 (이 중 3개가 중복으로 판정됨)

4. 생성된 클러스터 목록
- 기본물성시험
- 입도시험
- 컨시스턴시시험

- 밀도시험
- 강도시험
- 압밀시험

- 토질시험 실무

5. 기존 게시물 중복 제거 결과
- "체분석 시험방법", "들밀도 시험" 등 기존 작성된 5개의 제목과 의미상 겹치는 내용(공백 여부 무관)을 성공적으로 인식해 duplicate: true 처리하고 최종 결과에서 제외했습니다.

6. 테스트 실행 결과
- 에러 없이 깔끔한 통계 콘솔 출력을 보여주며 정상 동작합니다.

7. 향후 확장 포인트
- generate_content_candidates() 내에서 템플릿 기반 조합 대신 LLM(OpenAI/Gemini) API를 붙여 실제 검색어 기반 변형을 꾀할 수 있습니다.
- Google Search API를 연결해 실제 search_volume 데이터나 competition 데이터를 추출하는 함수 모듈을 붙이기 용이하게 설계되어 있습니다.
